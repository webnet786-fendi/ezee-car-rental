Paste your GitHub token

This page saves straight into the website's GitHub repository. It needs a token that can write to that one repository and nothing else. The token stays in this browser only.

How to create the token (once)
  1. GitHub → your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it ezee-admin. Expiration: up to 1 year.
  3. Repository access: Only select repositories → ezee-car-rental.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate, copy the token, paste it above.
